# pwa-glpi
PWA pour l'inventaire physique GLPI. Scannez un QR Code sur un équipement avec votre téléphone et la date d'inventaire du matériel correspondant dans GLPI est automatiquement mise à jour (champ `inventory_date` de la relation Infocom). Fonctionne en HTTPS avec un cache offline pour le shell de l'application.
